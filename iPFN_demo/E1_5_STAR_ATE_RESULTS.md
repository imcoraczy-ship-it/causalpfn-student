# E1.5 Star ATE 正式实验结果

本实验按冻结协议 `e1_5_star_ate_v1` 完成全部正式任务。产物验收通过不代表所有科学指标达标：J 的总体 Spillover 覆盖率为 **89.75%，未达到至少 90% 的目标**。完整原始证据 ZIP、原始审计材料和数学核验输入仅在本地保留，未随本公开 PR 提供。

## 实验设计与随机流

固定 N=200、M=50，星图中心节点为 0。`formal` 使用机制 1000–1019，每机制 10 次配对重复，每次固定中心 T=0、T=1，按 0→1 顺序执行。因此共有 **20 个机制、200 组配对重复、400 个上下文**。

每个上下文比较 `j`、`kernel-old`、`kernel-new`，共 1200 次点预测。J 每上下文计算一次名义 95% 区间，共 400 次区间计算、1200 个效应区间。

三个方法共享相同事实输入、真值和观测集合，预测器收到独立输入副本；模拟真值不提供给预测器。配对内共享叶子处理、噪声和观测索引，仅中心处理改变。没有因结果未达标而修改冻结算法、重抽种子、筛选机制或重跑任务。

随机流已核对冻结快照和当前 `scripts/e1_5_star.py` 的 `pair_rng()`，并逐条核对全部 400 条上下文记录：

- `DEFAULT_SEED=20261024`，`REPEAT_NAMESPACE=2026102501`，生成器为 PCG64。
- 配对重复 0：`entropy = 20261024 + mechanism_id`，不是固定使用 20261024。例如机制 1000 为 20262024。
- 配对重复 1–9：`entropy = [20261024, 2026102501, mechanism_id, pair_repeat_id]`。
- 每组先抽叶子处理，再抽噪声，再抽观测排列；中心 T=0/1 不另开随机流。

上述是配对流，不是机制生成流的替代。机制生成使用 dev 配置、`split_seed=331029`，底层 `seed_entropy()` 还包含命名空间 2026101605、split 的 SHA256 派生代码、setting/base-setting ID、N、机制 ID、通道 ID 和 repeat ID。真实配置和来源哈希保留在 `execution.json`。兼容接口的 `fit_seed` 不用于这三个冻结方法的训练或抽样。

ATE 为全体 200 个节点的平均效应，四状态顺序为 00、01、10、11：Direct=10−00，Spillover=11−10（treated spillover），Total=11−00。不是仅观测的 50 个节点、中心节点或叶子节点的平均效应。

## J 区间覆盖率

J 使用冻结模型的 95% 边际后验可信区间，不增加未来观测噪声，也不保证频率覆盖率达到名义值。

主要指标为 `covered / interval_requested`，保留失败请求于分母；同时报告 `covered / interval_valid`。本次所有 J 区间均有效，区间失败数均为 0，所以两种覆盖率相同。两个核 baseline 不支持该区间，覆盖率为 **N/A，不是 0%**。

| 分层 | 效应 | covered/requested | covered/valid | 覆盖率 | 平均宽度 |
|---|---|---:|---:|---:|---:|
| T=0 | Direct | 191/200 | 191/200 | 95.50% | 1.0772 |
| T=0 | Spillover | 180/200 | 180/200 | 90.00% | 2.9032 |
| T=0 | Total | 178/200 | 178/200 | **89.00%** | 3.2382 |
| T=1 | Direct | 195/200 | 195/200 | 97.50% | 1.6443 |
| T=1 | Spillover | 179/200 | 179/200 | **89.50%** | 2.0783 |
| T=1 | Total | 195/200 | 195/200 | 97.50% | 2.3432 |
| 总体补充 | Direct | 386/400 | 386/400 | 96.50% | 1.3608 |
| 总体补充 | Spillover | 359/400 | 359/400 | **89.75%** | 2.4908 |
| 总体补充 | Total | 373/400 | 373/400 | 93.25% | 2.7907 |

总体 Spillover、T=0 Total 和 T=1 Spillover 未达到 90%。不能把 89.75% 四舍五入表述为目标达成。

## 点估计比较

主分析按中心状态分层，每机制各有 10 次重复。误差定义为估计 ATE 减真实 ATE：绝对条件 bias 先计算每机制重复误差均值的绝对值，再平均机制；方差先计算每机制重复误差的 R−1 样本方差，再平均机制；RMSE 先平均机制内平方误差，再等权平均机制，最后开方。所有方法均为 20/20 完整机制，未通过删除失败或不完整机制改善排名。

下表每格依次为 **RMSE / 绝对条件 bias / 方差**：

| 方法 | 效应 | 中心 T=0 | 中心 T=1 |
|---|---|---|---|
| J | Direct | 0.2597 / 0.1106 / 0.0540 | 0.3523 / 0.2483 / 0.0205 |
| kernel-old | Direct | 0.2518 / 0.1109 / 0.0505 | 0.3564 / 0.2694 / 0.0125 |
| kernel-new | Direct | 0.2578 / 0.1158 / 0.0514 | 0.3330 / 0.2347 / 0.0171 |
| J | Spillover | 0.8553 / 0.6557 / 0.0161 | 0.6854 / 0.5496 / 0.0093 |
| kernel-old | Spillover | 0.9175 / 0.6462 / 0.0197 | 0.6263 / 0.4700 / 0.0287 |
| kernel-new | Spillover | 0.9361 / 0.7091 / 0.0135 | 0.6240 / 0.4759 / 0.0209 |
| J | Total | 0.9243 / 0.6902 / 0.1090 | 0.6025 / 0.5006 / 0.0419 |
| kernel-old | Total | 0.9772 / 0.6553 / 0.0814 | 0.5843 / 0.4343 / 0.0434 |
| kernel-new | Total | 1.0096 / 0.7487 / 0.0837 | 0.5802 / 0.4621 / 0.0504 |

T=0 下 J 的 Spillover 和 Total RMSE 较低；T=1 下两个核 baseline 的这两项 RMSE 均低于 J。因此不能声称 J 全面优于 baseline，也不以单项较低指标宣称统计显著优势。

中心分层是主分析。合并中心状态的 R−1 方差包含相关配对状态，仅作描述性补充，不能解释为来自独立重复的方差估计。总体覆盖率和 RMSE 也不能扩充独立机制数。

## 机制差异与独立数学核验

逐机制结果中，机制 1008 的 Spillover 覆盖率为 0/20，机制 1013 为 10/20。它们分别出现与 pilot 905 高估方向、907 低估方向类似的失准，不能通过移除这些机制来改善总体结果。详见展示副本 [分机制及中心状态诊断表](results/e1_5_star_ate_submission_v1/preview/j_coverage_by_mechanism_and_center.csv)；这不是同一机制的重复实验，也不构成偏差来源的因果识别。

数学核验仅读取保存的 pilot_fresh 输入及冻结权重，没有生成新样本或重新调用点预测接口。核验对象为机制 905 的 10 个上下文，以及机制 904、906、907 各两个代表上下文，共 **16 个上下文、48 个效应区间**。不是对全部 400 个正式上下文逐一独立复算。

独立实现采用系数空间高斯后验、erfc CDF 和 Brent 求根，与原观测空间求解及二分分位数算法比较；每上下文核验 8 个混合分量、权重归一化、分量均值/方差以及跨状态和跨节点协方差。

- 端点最大绝对差异：1.300626273348371×10⁻¹³。
- 原端点 CDF 与 0.025/0.975 的最大偏差：8.881784197001252×10⁻¹⁶。
- 后验混合均值与保存 ATE 点估计的最大差异：4.218847493575595×10⁻¹⁵。
- 协方差和 Total 方差恒等式检查通过，三个确定性自检通过。

这支持所核验上下文中的后验与分位数实现一致，未发现明确数学实现错误；它没有证明模型假设、跨机制外推、频率覆盖率或数据独立性正确。

## 节点误差与 Support 补充后处理

已从保存的真值、事实输入和三种方法逐节点预测完成补充分析，未新增模型预测、DGP或正式实验。全部20个机制、200组配对和400个上下文保留，按中心T分层；先汇总同一上下文的中心或199个叶子，再平均机制内重复并对机制等权。

四状态合并响应RMSE中，J在T=0的中心/叶子为0.468063/0.602225，T=1为0.431337/0.524968。J的叶子Spillover RMSE在T=0/1为0.769667/0.638342，Total为0.885179/0.666197，均高于对应中心节点。T=1时两个核baseline的叶子Spillover与Total RMSE均低于J，不能声称J全面优于baseline。

这里的主汇总 `rmse` 是上下文RMSE的机制等权平均，`pooled_rmse` 才是等权平均MSE后开方，两者不可混用；它们也不同于前文全体ATE误差的统计量。中心减叶子的效应差异与误差指标差异单独保存。

Support保留 `conditional_structural_zero`、`assignment_zero`、`observation_sampling_zero`、`covered` 四类。每个中心状态、每类节点各800个上下文×状态单元中，中心分别为400/200/159/41，叶子为400/0/0/400；这是上下文×状态计数，不是800个独立样本。中心是否被观测单列，经验Support不等同于模型 `arm_supported` 能力标记。
